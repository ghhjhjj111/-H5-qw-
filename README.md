# 求职招聘小程序多城市零工招聘H5网站小程序,兼职招聘小程序,人才招聘系统网站

源码地址：ym7k.com/19248/

这套零工招聘系统主打同城灵活用工、短期临时工、兼职岗位对接，一套代码同时支持微信小程序、H5、公众号三端，适合搭建本地零工市场、多城市兼职招聘平台，企业招工、个人找活双向互通。

### 🧑‍💼招工企业端

- 在零工广场发布招工岗位，可设置结算方式：日结 / 周结 / 月结
- 自定义薪资、招工人数、工作地点、行业分类，岗位可付费置顶提升曝光
- 进入用工大厅，浏览求职者简历，查看求职意向、期望薪资、意向地区、工作经验
- 一键邀约求职者，支持在线聊天沟通，也可直接拨打电话联系
- 管理自己发布的岗位、报名记录、聊天消息

### 👷求职者端

- 浏览附近、最新零工岗位，按地区、行业、薪资、结算方式筛选
- 订阅零工，有匹配新岗位推送通知
- 发布求职信息，填写意向岗位、期望日薪、工作经验、意向城市
- 岗位一键报名，和用工方在线私聊沟通岗位细节
- 消息中心统一管理聊天会话、系统通知

### 📌核心功能

1. **多端适配**：微信小程序、H5 网页、公众号，多城市分站
2. **岗位分类**：制造业、医疗、建筑、IT、餐饮、物流、零售、家政等行业
3. **结算标签**：日结、周结、月结，灵活区分临时工 / 长期工
4. **用工大厅**：集中展示全部求职简历，企业主动招人
5. **零工广场**：信息流展示招工岗位，置顶、刷新推广
6. **实时 IM 聊天**：企业与求职者在线私聊，消息红点提醒
7. **报名 & 邀约**：求职者报名岗位、企业发起求职邀约
8. **筛选检索**：地区、行业、薪资、结算方式多维度筛选
9. **后台管理**：岗位审核、简历管理、用户管理、广告配置、置顶套餐、分站管理
